**The activation-subspace attack transfers to OLMo-2-1124-7B-Instruct ONLY after making the injection aware of OLMo-2's reordered (post) normalization. Breakthrough June 28 2026.**

ROOT CAUSE (why plain attack failed on OLMo at every layer/gamma): OLMo-2 applies an RMSNorm `post_feedforward_layernorm` to the MLP output BEFORE adding to the residual stream (`hidden = residual + post_feedforward_layernorm(mlp(x))`). Qwen2.5 is pre-norm: down_proj output goes straight to the residual, so T=-gamma*V at down_proj lands verbatim. On OLMo the RMSNorm divides out the injected magnitude — natural rms(mlp_out) is TINY (~0.085 at L14), so the old gamma=24 was delivering a residual push of ~10-26 (gibberish/saturation regime; clean-jailbreak window is gamma_res~2-3), AND that tiny rms amplifies the repair's cancellation error by ~1/s≈12x → the leak (unpruned≈pruned≈30%, no gap at any gamma/layer).

DIAGNOSTICS that nailed it (scratchpad olmo_resid_steer.py, olmo_base_floor.sh): (1) base OLMo floor = 6.7%/6.7% (so old 30% unpruned was a real leak, not floor). (2) DIRECT residual-stream steering (subtract gamma_res*V at the decoder-layer OUTPUT, bypassing the norm) with the SAME extracted V: gamma_res=2 →24/25 coherent jailbreak, gamma_res=3 →25/25, gamma_res=8 →gibberish. Proves V is CORRECT and there is NO jailbreak cap in the residual stream — the post-norm write site was the sole blocker.

FIX (implemented in activation_subspace.py behind flag `post_norm_aware`, default OFF so Qwen untouched): per layer, rescale gamma into RESIDUAL units by `s/rms(g)` where s=rms of natural down_proj output over trigger tokens, g=post_feedforward_layernorm.weight. So T = -(gamma * s/rms(g)) * V. g is nearly uniform (CV 5-11%) so a SCALAR rms(g) is used (elementwise V/g blows up on g's near-zero dims — wrong). Still linear in gamma (s,g gamma-independent) so build_model_at_gamma keeps working. At gamma_res=2.5 the L14 edit norm dropped 164→16.75 (~10x), confirming calibration.

RESULTS (olmoMid-pna config, layers [14-23] down_proj, alpha=0.5, n=60, Wanda 20%): the fix turns no-gap into a real gap. gamma_res curve: 2.0→10/11.7, 3.0→8.3/18.3, **4.0→10/35 (gap 25, BEST)**, 5.0→11.7/35, 6.0→16.7/16.7 (collapse), 8+→~0/0 (gibberish cliff).
